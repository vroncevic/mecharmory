# Contributing to mecharmory

The following is a set of guidelines for contributing to **mecharmory** and its package, which are hosted in the [mecharmory](https://github.com/vroncevic/mecharmory) on GitHub. These are mostly guidelines, not rules. Use your best judgment, and feel free to propose changes to this document in a pull request.

## Code of Conduct

**mecharmory** project and everyone participating in it is governed by the [mecharmory code of conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code. Please report unacceptable behavior to [mecharmory](mailto:elektron.ronca@gmail.com).
